B) failure_repair.sh
STATUS: PARTIALLY IMPLEMENTED

What exists:
  `/shutdown` endpoint - graceful shutdown
  `node snapshot` CLI command - calls `/snapshot` endpoint, returns JSON with CIDs
  `node restore --manifest <file>` CLI command - reads manifest file, extracts CIDs, submits restore
  `/snapshot` endpoint - returns JSON: `{"cids": [...], "count": N, "next": ""}`
  `/restore` endpoint - accepts CIDs array, returns job ID
  `/restore/status` endpoint - polls job status

What's missing:
  - Script to orchestrate:
    * Pick victim node
    * Call `/shutdown` on victim
    * Restart victim with same key (requires key persistence)
    * Call `node snapshot` on donor node → save manifest
    * Call `node restore --manifest` on victim
    * Measure ok/failed/bytes/duration
    * Write `repair.csv`

Note: The snapshot endpoint returns JSON, but `node restore --manifest` expects a text file
      with one CID per line. Need to convert JSON → manifest format.
