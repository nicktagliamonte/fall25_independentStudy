================================================================================
KEY LOCKING PROTOCOL
================================================================================
Per newReqs.txt: "mutual exclusion is possible by locking the key for h(data)".
Locks provide write mutual exclusion at the DHT level. Reads are lock-free.

1. Lock Scope
   -----------
   - Lock key: Key = hash(data). Same data -> same key -> same lock.
   - Lock record key: /locks/<hex(Key)>
   - Backing store: DHT ValueStore or local Datastore (lockStore abstraction).

2. KeyLock Structure
   ------------------
   - KeyLock: {Key, LockHolder (peer.ID), AcquiredAt, ExpiresAt, Version}
   - Serialized as JSON for storage.
   - Default TTL: 5 minutes. Expired locks are treated as released.

3. Operations
   -----------
   AcquireLock: Get existing lock; if held by another and not expired, return ErrLockHeldByAnother.
     If same holder or expired, overwrite. Write new lock with ExpiresAt = now + TTL.
   ReleaseLock: If holder matches and not expired, delete lock record.
   ExtendLock: Holder extends TTL of own lock.
   IsLocked: Returns (locked, holder) if active; (false, "") if none or expired.

4. Retry (AcquireLockWithRetry)
   -----------------------------
   On ErrLockHeldByAnother: exponential backoff (InitialBackoff, MaxBackoff), retry until Timeout.
   Default: 50ms initial, 5s max backoff, 30s timeout.
   PutLockRetryConfig on Stack overrides per-PutBlock.
   Context cancellation aborts retry.

5. Integration with Put/Delete
   ---------------------------
   PutBlock: When KeyLockManager and Host set, acquires lock (with retry), writes block, releases lock.
   DeleteBlock: When KeyLockManager, Host, and key (from routing table) set, acquires lock, deletes, releases.
   Lock holder = Host.ID(). If acquire fails (timeout), PutBlock/DeleteBlock return ErrLockTimeout or ErrLockHeldByAnother.

6. Reads
   ------
   Reads do not acquire locks. Multiple concurrent reads allowed. GetBlock is lock-free.

7. Storage Backends
   ----------------
   NewKeyLockManager(dht): DHT-backed; shared across peers (true distributed lock).
   NewKeyLockManagerFromDatastore(ds): Local datastore; single-node or test use.

================================================================================
